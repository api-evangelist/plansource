# PlanSource API Documentation

> The PlanSource API provides the ability to obtain near real-time employee, dependent, and payroll deduction data without the need to use standard EDI files.

## Guides
- [What is the Benefits Administration API?](https://developer.plansource.com/docs/plansource-administrative-api.md): Empowering partners and developers to integrate with PlanSource like never before.
- [SAML 2.0 SSO Implementation](https://developer.plansource.com/docs/saml-20-sso-implementation.md): This document describes the implementation of SSO with PlanSource Benefits system via SAML 2.0.
- [Contact Support](https://developer.plansource.com/docs/contact-support.md)
